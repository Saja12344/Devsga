# Devsga

A static web project published from this repository. It contains the site entry point, reusable assets, and a custom domain configuration.

## Project structure

- `index.html` — main page
- `assets/` — images, fonts, and other static assets
- `CNAME` — custom-domain configuration

## Run locally

Open `index.html` in a browser, or serve the repository with any static web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This project can be hosted on GitHub Pages or any static hosting provider.
